# Empreendimento Mineiro SIG

Subpasta da Base GeoGoiás destinada aos mapas e dados geoespaciais de empreendimentos mineiros e processos minerários.

Registrar fonte, data, sistema de coordenadas e licença dos dados. Para shapefiles, preservar juntos .shp, .shx, .dbf, .prj e .cpg (quando disponível).
