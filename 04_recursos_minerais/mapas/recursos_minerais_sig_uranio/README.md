# Recursos Minerais SIG Urânio

Subpasta da Base GeoGoiás para armazenamento dos mapas e dados geoespaciais de Recursos Minerais SIG Urânio.

Registrar fonte, data, escala e sistema de coordenadas dos produtos. Para shapefiles, preservar juntos os arquivos .shp, .shx, .dbf, .prj e .cpg (se disponível).
